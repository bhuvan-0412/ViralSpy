# ViralSpy — Skills

## Frontend

- Next.js 14 (App Router, TypeScript)
- Tailwind CSS (light mode, coral #FF6B4A accent)
- Recharts (sparkline velocity charts)
- Lucide React (icons)
- Supabase Realtime (live trend updates)

## Backend

- Next.js API Routes (serverless, Vercel edge)
- Supabase Postgres (trends, briefs, profiles, snapshots)
- Row Level Security (per-user data isolation)
- Supabase Auth (Google OAuth + Magic Link)

## AI & Intelligence

- GPT-4o (content brief generation via structured JSON)
- Velocity scoring: (posts_per_hour / avg_posts_24h) \* 100
- Z-score anomaly detection (breakout signal before peak)
- Confidence scoring (0.0–1.0 trend reliability)
- Brief caching (never regenerate same trend twice)

## Data Sources

- YouTube Data API v3 (Shorts trending)
- RapidAPI Instagram Scraper (Reels hashtag velocity)
- Reddit Rising API (free, no key, early niche signal)

## DevOps

- Vercel (CI/CD, edge deployment)
- GitHub (version control, auto-deploy)

## Team Skills

- Full-stack (Next.js, TypeScript, Supabase)
- AI/LLM integration (GPT-4o, prompt engineering)
- Data pipeline (polling, velocity scoring, anomaly detection)
- UI/UX (Tailwind, creator-focused product design)
